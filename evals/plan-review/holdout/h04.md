# Lap timer display for a home rowing machine

## Brief

Show split time per 500 m on a small screen attached to my rowing machine, using the flywheel sensor that is already wired to an ESP32.

## Implementation

1. Count flywheel pulses with an interrupt and convert them to distance with a constant measured once.
2. Every second, compute the time for the last 500 m from the pulse timestamps.
3. Show the split and the total distance on a 128x64 OLED.
4. Reset the session when no pulse arrives for 30 seconds.
