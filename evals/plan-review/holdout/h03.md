# Reading log summary

## Brief

Make a monthly chart from my reading log spreadsheet: books finished per month and pages per day. It is for my own interest.

## Implementation

1. Read the spreadsheet with title, author, pages, start date and finish date.
2. Count books finished per month and average pages per day for each book.
3. Plot both as bar charts and save them as PNG files.
4. Skip rows without a finish date and print how many were skipped.
